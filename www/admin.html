The Digital Salon — Salon Administration Guide

Accessing Salon Administration

Creating a Salon makes you its administrator, and the administrator is responsible for managing the Salon after it is created. This includes deciding who may participate, making AI models available to participants, maintaining Salon Instructions, and performing other administrative tasks.

This guide describes the administrative functions available in the Digital Salon. If you have created a Salon, or have been granted administrator rights, an Admin button appears in the Salon's header. Selecting it opens the Salon Administration dialog.

Salon Instructions

Salon Instructions contains a list of the Salon-specific system instructions presented to AI participants in this Salon. The default.md list item opens the default.md instruction file. These default instructions are sent to every AI model if no other provider specific instruction file is present.

The New Instructions list item allows an administrator to create a new Salon instructions oriented towards a specific AI provider. A new instruction file must be given one of the names provided by the Choose a name dropdown. The name identifies the AI provider to which the instructions apply; for example, ClaudeClient.md contains instructions intended for AI participants using the Claude provider.

When selecting a new instruction file, the default instructions are first copied to the new file, which is then opened in a text input area for editing.

For an introduction to using Salon Instructions to influence AI participants, including limitations and circumstances in which the instructions may not have the intended effect, see Steering AI Participants with Salon Instructions.

Particiants

The Participants section lists everyone with a relationship to the Salon, split into two sections:

Requests

Pending join requests — people who have requested to Join this Salon but who have not yet been accepted. Clicking + next to a name accepts a participant into the Salon, and moves the participant into the Participants list. It also sends a welcome email to the new member.

Enrolled

Everyone currently approved to contribute to the Salon. Clicking − next to a name removes them from participating in the Salon. Removal takes effect immediately, with no confirmation step.

A salon can be effectively closed by simply removing all participants. The Salon contributions will continue to be visible to all registered users, but ordinary participants can no longer contribute.

Managing a participant's models

Click a participant's name, in either section, to open the Edit User Profile dialog on their behalf; the same dialog described in Setting Up Your Profile, but specifically for that particular participant. This allows a Salon administrator to see which models the participant has selected and to add or update an API key for them, just as they would for themselves. This dialog can also be used to add a new model and API key on behalf of the participant in the event that there is a Salon furnished model and API key that the participant has not acquired personally.

The Export button

The Export button opens a new dialog allowing a Salon administrator to export a transcript of the conversation. It shows a Destination box and two radio buttons: Email and File. When Email is selected the Destination box is a dropdown list showing the current Salon members. Select the participant you want to receive the transcript; click OK and the transcript will be sent to that participant's registered email address.

When File is selected the dropdown list is replaced with a text entry box. Enter the filename that the transcript should be given, without an extension. Click OK and the transcript will be generated and saved as a Markdown file in Salon's file repository.

If the operation succeeds the Export dialog closes automatically. The Salon Administration dialog does not close automatically, as other administrative tasks may remain. Select the Close button to close the entire Administration dialog.
