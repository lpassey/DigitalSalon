Obtaining an API key for an AI Model

The Digital Salon is a bring-your-own-key (BYOK) service. Rather than charging you for AI usage centrally, each participant connects directly to the AI providers they want to use. This means you control which models participate when you contribute, and you pay only for your own usage.

Before you can ask an AI model to respond in a Salon, you need to add an API key for that model's provider to your profile. This page explains generally how to obtain an API key from various providers

What is an API Key?

An API key is a long string of characters — often starting with a short prefix like sk- or AIza — that identifies you to an AI provider's service. Think of it as a password that lets the Digital Salon make requests to that provider on your behalf.

You create an API key by registering with the provider directly. Some providers offer a free tier or a free credit for new accounts, so you can try a model before committing to any cost, but such accommodations are becoming rare. In almost every case, when an API key is created it is displayed only once. It is therefore important that you create a safe storage environment for your API keys and that you copy them promptly to storage as soon as they are displayed.

Your API key is stored encrypted in the Digital Salon database. It is decrypted by the server only when needed to communicate with the corresponding AI provider. It is never displayed in the Digital Salon user interface and is never shared with other participants. It is transmitted only to the selected AI provider, over an encrypted network connection.

The sections below walk through some sample providers step by step.

Sample Providers

Mistral

Mistral is a European AI company whose models are efficient and perform well on structured analytical tasks. Mistral's smaller models are available at no cost, making them a good option for participants who want to try AI participation without any upfront expense.

  1. Go to console.mistral.ai and create an account.
  2. Open your profile or the API Keys section.
  3. Select Create new key, give the key a name such as "Digital Salon," and create it.
  4. Copy the key immediately. Mistral displays the complete key only once.

Pricing: Mistral claims to offer a free evaluation tier that includes access to their smaller models via the API at no cost, subject to rate limits, with no credit card required. Widespread reports from the internet indicate that this claim is illusory. Free "Experiment" keys trigger persistent HTTP 429 (code 1300) capacity rejections regardless of quota balances. Current model pricing is listed on Mistral's pricing page.1

Gemini — Google

Google's Gemini models are available through Google AI Studio. Gemini is particularly useful when a conversation benefits from Google's web-grounding capabilities, such as when a conversation involves recent events, current research, or facts that may have changed since an AI model's training data was collected.

Gemini models are known to be overly agreeable when not carefully steered by artfully crafted system instructions, so take that into consideration when using Gemini.

  1. Go to aistudio.google.com and sign in with your Google account.
  2. Select Get API key, then Create API key.
  3. If Google asks you to select a project, use the default project created by Google AI Studio. You do not need to create or manage a Google Cloud project specifically for Digital Salon.
  4. Copy the key and store it securely.

Pricing: Gemini Flash models once offered a generous free tier via Google AI Studio, allowing prototyping and light use at no cost subject to rate limits. These rate limits have been becoming increasingly restrictive, so do not rely on the Flash models to have good availability. Pro and more capable models require a paid plan. Google updates its model lineup and free tier terms regularly; check the pricing page for which models are currently available at no cost.2

DeepSeek

DeepSeek is an AI lab whose models perform particularly well on technical, mathematical, and quantitative analysis. They are also among the least expensive models available, which makes them a practical choice for conversations with high volumes of text.

  1. Go to platform.deepseek.com and register for an account.
  2. Go to API Keys in the left sidebar and click to create a new key.
  3. Copy the key and store it securely.

Pricing: DeepSeek is very inexpensive — a fraction of a cent per typical Salon exchange for most models. DeepSeek has recently introduced peak load pricing, but peak times are working hours in central China, so peak pricing is rarely an issue in the Western Hemisphere.3

Claude — Anthropic

Claude is made by Anthropic. It is well suited to examining the logical structure of arguments, identifying where conclusions outrun their evidence, and producing careful, methodical analysis.

  1. Go to console.anthropic.com and create a free account.
  2. Once logged in, select API Keys in the left sidebar.
  3. Click Create Key, give it a name (e.g. "Digital Salon"), and copy the key that appears. You will only see it once, so copy it before closing the window.

Pricing: Anthropic charges per token (roughly per word processed). Claude Haiku is the least expensive model and handles most conversational tasks well. Claude Sonnet and Opus cost more but reason more carefully on complex problems. There is no persistent free tier; you will need to add a prepaid credit balance before your key will work. Usage in a typical Salon conversation is modest.4

ChatGPT — OpenAI

OpenAI's models are widely used and perform well at checking whether specific citations exist, verifying that sources say what is claimed, and general analytical tasks.

  1. Go to platform.openai.com and sign up for an account.
  2. Open the menu under your name in the top right and select API keys.
  3. Click Create new secret key. Copy the key immediately — OpenAI shows it only once.

Pricing: OpenAI charges per token and requires a prepaid credit balance before API keys will function. There is no automatic free trial credit; you will need to add a minimum balance (currently $5) before making your first request. Once funded, costs per typical Salon exchange are modest. Current model options and per-token rates are listed on OpenAI's pricing page.5

  2. Google publishes current Gemini API pricing and free tier limits at ai.google.dev/pricing. Free tier limits and eligible models change; check there before assuming a model is free.
  3. DeepSeek publishes current pricing at platform.deepseek.com/api-docs/pricing. The free token allowance terms for new accounts may change.
  4. Anthropic publishes current pricing at anthropic.com/pricing. Rates change over time; check there for current figures.
  5. OpenAI publishes current pricing at openai.com/api/pricing. The minimum prepaid balance requirement may change; check the platform for current billing terms.
